# WaldOT API

Core Java API module for WaldOT.

## Scope

This module provides the shared contracts and base implementations used by
WaldOT runtimes and plugins, including:

- graph model interfaces and strategy contracts;
- OPC-UA integration abstractions;
- DTDL parsing utilities;
- JEXL execution helpers;
- security/network/system helper utilities.

## Build and test

From the repository root:

```bash
./gradlew :waldot-api:test
```

Coverage report is generated by JaCoCo under:

- `waldot-api/build/reports/jacoco/test/html/index.html`

## Notes

- This module targets the same Java version configured by the multi-module build.
- Public contracts in `net.rossonet.waldot.api` are consumed by multiple plugins,
  so compatibility should be preserved when possible.
