    Key Concepts¶

    What is WaldOT?¶

    WaldOT is a Digital Twin Engine that creates a living bridge between:

    • OPC UA (industrial automation standard)
    • Apache TinkerPop (graph database framework)

    This enables:

    • Real-time bidirectional synchronization between OPC UA and graph databases
    • Complex graph queries on industrial data using Gremlin
    • Event-driven automation with the rules engine
    • Edge computing capabilities for low-latency processing

    Key Features¶

    1. Unified OT/IT Data Model
    2. OPC UA Objects → TinkerPop Vertices
    3. OPC UA References → Graph Edges

    4. OPC UA Variables → Vertex Properties

    5. Powerful Graph Queries

    6. Gremlin query language for complex traversals
    7. Real-time queries on live industrial data

    8. Graph algorithms (PageRank, shortest path, community detection)

    9. Event-Driven Rules Engine

    10. IF-THEN-THAT rules with JEXL expressions
    11. Priority-based event processing
    12. Hysteresis deduplication

    13. Full graph access in rule conditions and actions

    14. Data Generation & Simulation

    15. 6 algorithms (random, sinusoidal, triangular, etc.)
    16. Perfect for testing without physical hardware

    17. Thousands of concurrent generators with virtual threads

    18. Edge-First Architecture

    19. Runs on-device (RTUs, industrial PCs, edge gateways)
    20. Low latency, offline capable
    21. Bandwidth efficient

    Technology Stack¶

    • Java 26 (build target) - virtual threads for massive concurrency
    • Eclipse Milo - OPC UA server implementation
    • Apache TinkerPop 3.x - Graph database framework
    • Apache Commons JEXL - Expression language for rules
    • Docker - Containerized deployment
